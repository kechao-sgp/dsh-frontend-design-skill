# 示例：素页 · 旧书修复工作室

用 `deepseek-frontend-design` 技能现场产出的一页，作为技能输出的实证。店名、地址、报价均为虚构；四张图版是带许可的真实照片。

直接打开 `index.html`。`shots/` 是 375 / 768 / 1280 三档整页截图（Chrome headless，DPR 2，webp）。

## 设计计划

| 项 | 内容 |
| --- | --- |
| 色彩 | 纸 `#f4efe3` / 纸深 `#ece4d2` / 墨 `#191510` / 次文 `#62594a` / 朱红 `#9c3529` / 细线 `#cdc3ad` |
| 字体 | 标题宋体（Songti SC → Source Han Serif SC → Noto Serif SC），正文苹方；H1 clamp(3rem, 8.2vw, 6.75rem)，H2 1.5–2.25rem，正文 17px/1.85 |
| 版式 | 出版图录式：封面文字 5fr / 图版 7fr 右侧出血；线装针脚图版整幅出血横贯；工序与报价回到单列正文，量宽 33em |
| 记忆点 | 图版本身——四张实拍照片用 `mix-blend-mode: multiply` 融进纸色，看起来像印在同一张纸上；其余全部退到字与细线 |

自审：把「宋体大标题 + 朱红 + 纸色」套到任何一家手作工作室都成立，所以识别度不押在装饰上，而是押在「照片像印刷品一样印在纸里」这一件事——同一手法只出现在图版上，文字区一律留白。

## 自检表（实测，非声明）

| 项 | 结果 |
| --- | --- |
| 对比度 | 墨/纸 15.83:1；次文/纸 6.01:1；朱红/纸 6.19:1（小字阈值 4.5:1，通过；细线 1.52:1 仅作分隔，不承载文字） |
| 字体 | 2 个家族；字号 13 / 14 / 15 / 17 / 18 / 20 / 36 / 105；正文行高 1.85，量宽 561px ≈ 33 字/行 |
| 间距 | 4 与 8 的倍数：8 / 12 / 16 / 20 / 24 / 28 / 32 / 48 / 56 / 72 / 96 |
| 三档 | 375 / 768 / 1024 / 1280 / 1440 实测 `scrollWidth === clientWidth`，无横向滚动 |
| 焦点 | Tab 顺序 2 项（工序与报价 → 邮件），均为 2px 朱红 outline + 4px offset，实测可见 |
| reduced-motion | 媒体查询在位，封面图版 clip-path 揭示动画归零 |
| 图片 | 4 张 webp 全部加载完成（1700 / 2200 / 1500 / 1500 px 宽），带尺寸属性与替代文本 |
| 反模板 | 无渐变文字、无毛玻璃、无居中式 hero、无 kicker/eyebrow、无节序号、无卡片上浮、无 fade-up 段落 |

失败与取舍记录：先用图像生成模型出「纸纤维特写」，四个 provider 均未配置密钥，全部失败；改用 Wikimedia Commons 的公共领域/CC 照片，许可与作者写进页脚。照片是彩色的，为了不撞纸色，统一走 multiply 混合而不是加滤镜。

复测方式见技能目录 `references/critique.md` 里的对比度脚本；截图脚本为 Chrome headless + CDP（`Page.getLayoutMetrics` 取内容高度，分片截取再拼接）。
