# 示例：素页 · 旧书修复工作室

用 `deepseek-frontend-design` 技能现场产出的一页，作为技能输出的实证。虚构店名与报价，只用于展示版面与排版判断。

直接打开 `index.html` 即可；`shots/` 是 375 / 768 / 1280 三档的整页截图（Chrome headless，DPR 2）。

## 设计计划

| 项 | 内容 |
| --- | --- |
| 色彩 | 纸 `#f4efe4` / 纸深 `#e9e1d0` / 墨 `#1c1a17` / 次文 `#6b6357` / 朱红 `#a63d2f` / 细线 `#d3c8b2` |
| 字体 | 标题宋体（Songti SC → Noto Serif SC），正文黑体（PingFang SC → Noto Sans SC）；阶梯 14 / 16 / 20 / 40 / 56 |
| 版式 | 桌面：左侧 96px 书脊轨道（竖排题签 + 缝线），正文单列贴齐；移动：书脊塌成顶部一条标签 |
| 记忆点 | 贯穿整页的书脊缝线（朱红短线，`repeating-linear-gradient`），全页仅此一处装饰 |

自审：把这套配色和「左侧窄轨 + 单列正文」套到任意一家手作工作室都成立——所以记忆点只压在缝线上，其余全部退到纸色与细线里；工序编号用汉字一、二、三、四，因为四道工序本身有先后，不是为了好看。

## 自检表（实测，非声明）

| 项 | 结果 |
| --- | --- |
| 对比度 | 墨/纸 15.14:1；次文/纸 5.16:1；朱红/纸 5.5:1（正文阈值 4.5:1，全部通过；细线 1.44:1 仅作分隔，不承载文字） |
| 字体 | 2 个家族，正文 16px，阶梯 14 / 16 / 20 / 40 / 56 共 5 级 |
| 间距 | 4 与 8 的倍数：12 / 16 / 18(≈) / 20 / 24 / 28 / 48 / 72 / 96 |
| 三档 | 375 / 768 / 1280 均无横向滚动（`scrollWidth === clientWidth`），无截断 |
| Tab | 4 个 `summary` + 1 个 mailto 链接，焦点框 2px 朱红 + 3px offset 实测可见 |
| reduced-motion | 媒体查询存在，且全页无入场动画（只保留 `details` 的展开） |
| 反模板 | 无紫蓝渐变、无毛玻璃、无居中 hero、无 emoji、无 01/02/03、无 hover 上浮、无 fade-up |

复测方式见技能目录 `references/critique.md` 里的对比度脚本。
