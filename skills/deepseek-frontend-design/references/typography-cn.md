# 中文排版参考

英文排版规则搬到中文界面会坏掉一半：中文没有词间空格、没有大小写、字形更密。下面是可以直接用的一组规则。

## 字体栈

```css
/* 正文：系统优先，跨平台都有 */
--font-sans: "PingFang SC", "Hiragino Sans GB", "Noto Sans SC",
  "Source Han Sans SC", "Microsoft YaHei", sans-serif;

/* 标题衬线：需要"印刷感"时才用 */
--font-serif: "Songti SC", "Noto Serif SC", "Source Han Serif SC", serif;

/* 数字与代码 */
--font-mono: "SF Mono", "JetBrains Mono", "Source Code Pro", Menlo, monospace;
```

- 不要为了"好看"引入 3MB 的中文字体包。真要用，选可变字重 + 子集化 + `font-display: swap`，并保留系统栈兜底。
- 标题衬线只适合编辑、文化、出版、餐饮等题材。SaaS 后台强行上宋体会显得虚假。

## 字号与行高

| 用途 | 字号 | 行高 |
| --- | --- | --- |
| 正文 | 16–18px | 1.7–1.9 |
| 次要说明 | 14–15px | 1.6 |
| 小标签 | 12–13px | 1.4 |
| 小标题 | 20–24px | 1.4 |
| 章节标题 | 32–40px | 1.25 |
| 主视觉 | 48–72px | 1.1–1.15 |

中文行高比西文大：字面率高、笔画密，1.5 会挤。正文最小 16px；12px 的中文只在标签、角标里出现。

## 行长

每行 28–40 个汉字。16px 正文对应约 640–720px 内容宽度。超过 45 字，眼睛回行会丢行。侧栏、卡片内文字更短，20–28 字。

## 中西混排

```css
/* 现代浏览器：自动在中西文之间加 1/4 空隙 */
body { text-spacing-trim: space-first; }
/* 不支持时的手写方案：在模板里显式加空格，例如「支持 Markdown 导出」 */
```

- 数字与中文之间同上：「3 天」「98%」。
- 中文与英文单词之间留一个半角空格的视觉宽度，不要用全角空格。
- 单位紧跟数字：「16px」「3.5 万」，单位与中文之间加空格。

## 标点

- 引号：简体用「」或“”，不要用直引号 `"`。
- 省略号用单个字符 `……`，不要 `...`。
- 破折号用 `——`（占两字），不要 `--`，不要在中英文之间硬接。
- 中文句末用「。」，界面短标签可省略句号，但同一屏内保持一致。
- 冒号：中文全角「：」用于正文，界面标签后不需要冒号。

## 数字

```css
.data-table td { font-variant-numeric: tabular-nums; text-align: right; }
```

- 金额、比例、时间列右对齐，小数位数统一。
- 千分位与货币符号位置固定：「¥ 12,480.00」。
- 电话、编号、版本号用等宽数字，避免跳动。

## 字重

- 中文只有 400 / 500 / 700 可靠可用，300 在多数系统上会被合成得很脏。
- 层级优先用字号和颜色差，其次才是字重；一段话里同时用三种字重会乱。
- 深色背景上的中文用 400 而不是 300，笔画会糊。

## 常见错误

1. 用 `letter-spacing: 0.1em` 拉开中文 —— 只对英文标签有效，中文会散架。
2. 全大写英文 eyebrow 叠在中文标题上 —— 两种语言的大写/字号习惯冲突。
3. 中文正文用 14px + 行高 1.4 —— 屏幕上读三行就累。
4. 用宋体做 UI 正文 —— 笔画细节在小字号下糊成一团。
5. 卡片里放整段中文而不限制行长 —— 一行 60 字以上。
6. 中英混排不加空格 —— 「使用React构建」读起来粘连。
7. 用 `text-align: justify` 处理短中文段落 —— 字距被拉得不均匀。
